## Purpose

The Dashboard is the central control panel of the CRM.

It provides users with quick access to
business information, statistics,
notifications and system features.

The Dashboard should be clean, fast,
professional and easy to use.

## Security Rules

• Dashboard opens only after successful login.

• Session must be verified before loading.

• Unauthorized users cannot access dashboard.

• Logout must destroy the active session.
