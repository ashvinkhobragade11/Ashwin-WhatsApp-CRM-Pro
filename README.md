# Ashwin WhatsApp CRM Pro

A modern desktop CRM platform built with Python and CustomTkinter.

This project is being developed with a strong focus on clean architecture, modular design, performance, security, and future scalability.

---

## Current Features

- Dashboard
- Contact Management
- Add Contact
- Edit Contact
- Delete Contact
- Search Contacts
- Import Contacts (CSV)
- Export Contacts (CSV)
- Dashboard Analytics
- Recent Activity System

---
